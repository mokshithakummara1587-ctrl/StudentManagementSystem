# Student Grade Tracker

A simple Java console-based application for managing student grades.

## Features

- Add student
- Display students
- Calculate average marks
- Find highest score
- Find lowest score
- Search student
- Update marks
- Delete student
- Calculate grade
- Check pass/fail status

## Technologies Used

- Java
- ArrayList
- Scanner
- Loops
- Methods
- If-else
- Switch

## How to Run

Compile:

javac StudentGradeTracker.java

Run:

java StudentGradeTracker
